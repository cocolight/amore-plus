如何使用 amore-plus 主题

2026-10-18 • 示例文章 • 使用指南

amore-plus 是一款面向 Gridea-Pro 的极简博客主题，聚焦阅读体验。无独立构建与运行时，由宿主平台在渲染期生成静态页面。

一、安装与启用

本主题是纯静态资源，无运行时依赖。将 src/ 目录复制到 Gridea-Pro 的主题目录即可：

# Linux / macOS
cp -r src ~/文档/blog_data/themes/amore-plus

# Windows（PowerShell）
Copy-Item -Recurse src "$env:USERPROFILE\Documents\Gridea Pro\themes\amore-plus"

随后在 Gridea-Pro 客户端「主题」中启用 amore-plus，并在主题设置面板中填写各项配置。

二、主题设置

主题提供 25 项可配置项，集中在 config.json 的 customConfig，按分组呈现：

分组包含项
基础设置站点 Logo、站点图标、页脚信息
首页信息地理位置、格言内容、格言作者
外观设置默认主题（深色 / 浅色）、主题强调色
社交链接GitHub、Twitter、微博、知乎、Facebook
统计分析Google Analytics 跟踪 ID
Giscus 评论仓库、repoId、分类、映射方式等 9 项
高级设置自定义 CSS、自定义 JavaScript

2.1 强调色如何生效

「主题强调色」会影响链接、按钮、目录高亮条与顶部进度线。你可以在页面右上角切换明暗主题，观察颜色与对比度的变化。

三、主要功能

3.1 文章目录（TOC）

正文中的 h2 / h3 会被自动提取为右侧目录，点击可平滑跳转。滚动页面时目录会自动高亮当前章节并跟随滚动，无需手动翻动。

若某篇文章不含标题，目录会自动隐藏，不留空壳。

3.2 阅读进度

页面顶部有一根细线（3px），颜色跟随强调色，随阅读进度从 0% 逐渐填充至满宽，不使用任何文字。

3.3 明暗双主题

访客首次访问按「默认主题」设置显示；切换后的选择会记在浏览器本地，下次访问保持一致。

3.4 闪念与热力图

支持短内容记录（memos），并以 GitHub 风格贡献热力图呈现，列表采用客户端分页。

3.5 评论系统

支持 Giscus、Gitalk、Valine、Waline、Disqus 五套系统。为避免干扰阅读，闪念 / 友链 / 关于页不显示评论区。

四、使用须知

本主题的模板使用 Pongo2（Django 风格） 方言，不是标准 Jinja2：

  • 默认值过滤器为 {{ x|default:"" }}（冒号语法，不接受第二个参数）
  • 循环下标使用 forloop.Counter0 而非 loop.index
  • 向 JavaScript 字符串插值时，请加上 |escapejs

五、获取主题
